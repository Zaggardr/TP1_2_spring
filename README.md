Java Reflection & Spring IoC

Two practical exercises exploring dependency management in Java and Inversion of Control with Spring.

## TP1 — Reflection
Demonstrates dynamically loading implementations and injecting dependencies using Java reflection.

## TP2 — Spring IoC
Demonstrates Spring Beans, Inversion of Control and Dependency Injection using annotations and `AnnotationConfigApplicationContext`.

## Stack
Java · Spring Framework · Reflection · Dependency Injection

## Learning Objective
Understand the transition from manually managed dependencies to container-managed dependency injection.
